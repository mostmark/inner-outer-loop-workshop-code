# Inner & Outer Loop Workshop

## Overview

This two-part hands-on workshop gives developers an experience of the inner and outer loop of
cloud-native application development on Red Hat OpenShift.

- **Part 1: Inner Loop** – code, build and deploy the Coolstore microservices (Quarkus,
  Spring Boot, .NET, Node.js) from OpenShift Dev Spaces, add health probes and externalize their
  configuration.
- **Part 2: Outer Loop** – build with OpenShift Pipelines (Tekton), deliver with GitOps and
  Argo CD, and connect and observe the services with OpenShift Service Mesh and Kiali.

The Coolstore application you work with is in [`labs/`](labs). Follow the lab guide from your
instructor for the exercises.
